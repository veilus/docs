## Tags

Tags are colored labels you put on profiles.

- When creating a profile, the **Organize** step lets you pick tags or add new ones. In **Batch create** the tags apply to every profile in the batch.
- On an existing profile, open its panel. The **Overview** tab shows **Tags**: click a tag to put it on or take it off, or type a **New tag name** and click **Add**.
- Click a tag's color dot to change its color (red, orange, amber, green, teal, blue, violet or pink).

Click **Save Changes** to keep tag changes.

## Filter the profile list

Type in the **Filter…** box above the profile list. Suggestions are grouped by:

| Group | Filters by |
|-------|-----------|
| **Tag** | Profiles with a tag |
| **Status** | Running, stopped and so on |
| **OS** | The profile's OS |
| **Proxy pool** | Profiles assigned to a pool |
| **Last used** | Used in the last N days, or unused for N or more days |
| **Name** | Name contains some text |

Each filter becomes a chip; click its ✕ to remove it, or **Clear all**. With a filter active, **Assign Pool** in the page header assigns a pool to every profile in the filtered list.

## Saved filters

To keep a filter you use often, click **Save this filter** and give it a name. It appears under **Saved filters** in the sidebar; click it to apply it again.

- After changing an applied saved filter, choose **Save changes to "name"** or **Save as new…**.
- Each saved filter's menu has **Rename**, **Update with current filters** and **Delete…**.
- Drag saved filters to reorder them.

## Notes

The **Overview** tab of a profile has **Notes** for anything about it: account, purpose, reminders. Click **Save note** to keep it.
