---
title: Keyboard Shortcuts
description: Keyboard shortcuts in the Veilus app.
---

These shortcuts work in the Veilus app window. Inside a launched profile, the browser uses the usual Chromium shortcuts.

On macOS, use <kbd>Cmd</kbd> where the table says <kbd>Ctrl</kbd>.

## Anywhere in the app

| Shortcut | Action |
|----------|--------|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Go to the profile filter bar (switches to **All profiles** if you are on another page). Does nothing while you are typing in a text field. |
| <kbd>Esc</kbd> | Close the profile panel and most dialogs. |
| <kbd>Cmd</kbd>+<kbd>Q</kbd> (macOS) | Quit Veilus. Closing the window only hides Veilus in the tray; on Windows, use **Quit Veilus** in the tray menu. |

## Profile filter bar

| Shortcut | Action |
|----------|--------|
| <kbd>↓</kbd> / <kbd>↑</kbd> | Open the suggestions and move through them |
| <kbd>Enter</kbd> | Apply the highlighted suggestion |
| <kbd>Esc</kbd> | Close the suggestions |
| <kbd>Backspace</kbd> in an empty field | Remove the last filter |

## Saved filters (sidebar)

| Shortcut | Action |
|----------|--------|
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>Alt</kbd>+<kbd>↓</kbd> | Move the focused saved filter up or down |
| <kbd>Enter</kbd> / <kbd>Esc</kbd> while renaming | Save / cancel the new name |

## Veilus Flow diagram editor

| Shortcut | Action |
|----------|--------|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> or <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Redo |
| <kbd>Esc</kbd> | Exit fullscreen |

## Script tags (Veilus Flow)

| Shortcut | Action |
|----------|--------|
| <kbd>Enter</kbd> or <kbd>,</kbd> | Add the typed tag |
| <kbd>Backspace</kbd> in an empty field | Remove the last tag |
