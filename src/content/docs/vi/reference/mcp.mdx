[MCP (Model Context Protocol)](https://modelcontextprotocol.io) là cách chuẩn để các công cụ LLM như Claude Code, Cursor, Claude Desktop kết nối tới công cụ bên ngoài — Veilus nói giao thức này qua stdio, nên một LLM có thể liệt kê, mở profile của bạn và viết, chạy script [Veilus Flow](/vi/recipes/llm-scripts/) thay bạn.

Giống [REST API](/vi/reference/rest-api/), tính năng này cần bật API cục bộ trước, từ trang **API & MCP** trong sidebar của app — trang đó cũng đúc token bạn cần dưới đây.

## Kết nối

Binary Veilus có lệnh con `mcp` nói MCP qua stdio. Client cần đường dẫn tới binary đó và token của bạn, truyền qua biến môi trường `VEILUS_API_TOKEN`.

### Claude Code

```bash
claude mcp add veilus -e VEILUS_API_TOKEN=<token> -- "<path to Veilus>" mcp
```

### Cursor / Claude Desktop

Thêm đoạn này vào cấu hình MCP server của client:

```json
{
  "mcpServers": {
    "veilus": {
      "command": "<path to Veilus>",
      "args": ["mcp"],
      "env": {
        "VEILUS_API_TOKEN": "<token>"
      }
    }
  }
}
```

Trang **API & MCP** tự điền đường dẫn binary thật và token cho bạn ngay khi bạn đúc token — copy đoạn cấu hình từ đó thay vì tự gõ.
